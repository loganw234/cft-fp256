cft-fp256 — the tile behind a WebSocket

One WebSocket message carries exactly one frame of docs/REMOTE.md, unchanged. This page speaks those frames to cft-serve --ws PORT, and checks every answer against the wasm module loaded beside it: the library is the contract, so a remote result that differs from a local one is a fault in the transport until proven otherwise.
